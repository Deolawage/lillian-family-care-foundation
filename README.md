# lillian-family-care-foundation


Lillian Family Care Foundation is a fully responsive, multi-page demo website built for a Nigerian NGO dedicated to empowering underserved communities through education, healthcare, and youth development. The site was designed and developed from scratch using HTML, CSS, and JavaScript, with a strong focus on clean structure, visual storytelling, and user experience.

The design uses Playfair Display for elegant headings and DM Sans for readable body text, creating a professional aesthetic suited to a non-profit organisation. Key sections include a full-screen hero with impact statistics, a programs section highlighting three core initiatives, a testimonials section featuring real community stories, and a donation call-to-action banner.

The site is fully mobile responsive with a hamburger navigation menu for smaller screens. Real photography is used throughout to humanise the foundation's work and build donor trust. The footer includes contact details and CAC registration information for credibility.

This project demonstrates practical skills in semantic HTML, CSS typography and layout, responsive design, and JavaScript DOM manipulation. It was built as a real freelance project — a fully functional professional deliverable, not a practice exercise. The codebase is clean and structured for easy content updates by non-technical staff.
